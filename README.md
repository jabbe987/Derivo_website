# Derivo Website

This repository contains the Derivo marketing site.

## Getting started

- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build: `npm run build`
- Preview build: `npm run preview`

## Project structure

- `src/` React app
- `public/` static assets

## Deployment

Deploy the `dist/` output from `npm run build` to your hosting provider.
